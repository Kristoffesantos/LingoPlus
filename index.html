About LingoPlus

Who is it for?

  • Hobbyists

Why LingoPlus?

IT has many acronyms and technical terms that can be confusing at first. LingoPlus gives short and simple explanations so beginners can understand them faster.

IT Terms

Search and learn common IT terms, acronyms, networking terms, programming concepts, and web development terms.

API

Allows different software programs to communicate with each other.

RAM

Temporary memory used by a computer while programs are running.

ROM

Memory that stores data that normally remains available even when power is off.

CPU

The main processor that performs instructions and calculations.

GPU

A processor designed mainly for graphics and parallel calculations.

GUI

A visual interface that lets users interact with software using buttons and menus.

OS

Software that manages computer hardware and applications.

SSD

A storage device that uses flash memory to store data.

HDD

A storage device that uses magnetic disks to store data.

BIOS

Firmware that helps initialize computer hardware when a computer starts.

Hardware

The physical parts of a computer that you can touch.

Software

Programs and instructions that run on a computer.

HTML

The language used to structure content on web pages.

CSS

Used to style and design HTML websites.

JavaScript

A programming language commonly used to make websites interactive.

URL

The web address used to locate a resource online.

HTTP

A protocol used to transfer information between browsers and servers.

HTTPS

The secure version of HTTP that encrypts communication.

DOM

A representation of a web page that JavaScript can interact with.

Frontend

The part of a website that users see and interact with.

Backend

The server-side part of an application that handles data and logic.

Responsive Design

A design approach that allows websites to work on different screen sizes.

Browser

A program used to access and view websites.

Web Server

A server that delivers web pages and other web resources.

Website

A collection of related web pages available through the internet.

Web Page

A single document that can be viewed in a web browser.

DNS

Converts domain names into IP addresses.

IP Address

A numerical address used to identify a device on a network.

IP

Internet Protocol used for addressing and sending data across networks.

TCP

A protocol that provides reliable delivery of data across networks.

UDP

A faster network protocol that does not guarantee delivery.

LAN

A network that connects devices within a small area.

WAN

A network that covers a large geographic area.

Wi-Fi

Wireless technology used to connect devices to a network.

Router

A device that directs network traffic between different networks.

Switch

A networking device that connects devices within a network.

Port

A number used to identify a specific network service.

Bandwidth

The amount of data that can be transferred over a network in a given time.

Latency

The delay between sending and receiving data.

Upload

Sending data from your device to another system or server.

Download

Receiving data from another system onto your device.

Database

An organized collection of information that can be stored and managed.

SQL

A language used to work with data stored in relational databases.

JSON

A common text format used to store and exchange structured data.

Table

A database structure made up of rows and columns.

Record

A single row of information in a database table.

Query

A request for information or an operation on stored data.

CRUD

Create, Read, Update, and Delete are common database operations.

Firewall

A security system that controls network traffic.

Encryption

Converting information into a protected form to prevent unauthorized access.

Authentication

The process of verifying who a user is.

Authorization

The process of determining what an authenticated user can access.

Malware

Software designed to harm, disrupt, or gain unauthorized access to systems.

Virus

A type of malicious program that can spread by attaching itself to files.

Phishing

A scam that attempts to trick people into giving away sensitive information.

Backup

A copy of data kept so it can be recovered if the original is lost.

Algorithm

A step-by-step procedure used to solve a problem.

Variable

A named location used to store a value in a program.

Function

A reusable block of code designed to perform a specific task.

Array

A structure that stores multiple values in a single variable.

Loop

A programming structure that repeats a block of code.

Condition

A rule that determines whether certain code should run.

Object

A programming structure that can store related data and behavior.

Syntax

The rules that determine how code must be written.

Compiler

A program that translates source code into another form that a computer can run.

Interpreter

A program that executes code by processing it during runtime.

Runtime

The environment where a program is executed.

Debugging

The process of finding and fixing problems in code.

Bug

An error or problem in a program.

IDE

Software that provides tools for writing, testing, and debugging code.

Framework

A collection of tools and structures used to build software.

Library

A collection of reusable code that developers can use in projects.

Git

A version control system used to track changes in files and code.

GitHub

An online platform used to store and collaborate on Git repositories.

Repository

A location where project files and their version history are stored.

Commit

A saved set of changes in a Git repository.

Branch

A separate development version of a project.

Merge

Combining changes from different branches into one branch.

Pull Request

A request to review and merge changes into another branch.

README

A file that explains important information about a project.

Cloud Computing

Using remote internet-based servers to store data or run services.

Hosting

A service that stores website files so people can access the site online.

Deployment

The process of making a website or application available to users.

Localhost

A local environment used to run and test websites or applications.

Node.js

A runtime that allows JavaScript to run outside of a web browser.

CMS

A system used to create and manage digital website content.

UI

User Interface; the visual parts of a system that users interact with.

UX

User Experience; how users interact with a product or system.

Cookie

Small pieces of data stored by a website in a user's browser.

Cache

Stored data that helps websites and applications load faster.

Open Source

Software whose source code is available to inspect or modify.

Package

A collection of software files or code distributed for use in a project.

If Statement

if (age >= 18) {
    console.log("Adult");
}

Runs code when a condition is true.

If Else

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

Chooses between two conditions.

For Loop

for (let i = 0; i < 5; i++) {
    console.log(i);
}

Repeats code a specific number of times.

While Loop

while (x < 5) {
    x++;
}

Repeats code while a condition is true.

Array

    "Apple",
    "Banana",
    "Mango"
];

Stores multiple values.

Array Access

console.log(fruits[0]);

Accesses an item in an array.

Array Push

fruits.push("Orange");

Adds an item to an array.

Object

let student = {
    name: "Alex",
    age: 19
};

Stores related information.

DOM Selection

    "title"
);

Change Text

document.getElementById(
    "title"

Click Event

    "click",

        alert("Clicked!");
    }

Console Log

console.log("Hello");

String

Number

Comparison

age === 18

Logical AND

age > 18 && score > 50

Logical OR

age > 18 || score > 50

Checks if at least one condition is true.
